rcmd — 像本地一样运行远程命令

在远程 telnet 或 ssh 设备上执行命令，就像在本地运行一样简单。为 AI 工具（Claude Code 的 Bash 工具）和人类使用而设计。

为什么做这个

让 AI「像本地一样」跑远程命令，真正的难点不是连接，而是三件事，现有工具各缺一环：

方案缺陷
ssh host cmd无状态 —— cd/环境变量跨调用不保留
tmux send-keys拿不到准确的命令边界和退出码
telnet没有干净的自动化方式（嵌入式设备常用）

rcmd 一次解决这三点：有状态、准确退出码、telnet/ssh 统一接口。

架构

调用方 ──▶ rcmd（瘦客户端，每次调用新进程） │ Unix socket（长度前缀 JSON） ▼ rcmd daemon（常驻后台） ├─ session[board] → pexpect telnet 长连接（有状态） └─ session[server] → pexpect ssh 长连接（有状态）

daemon 首次调用时自动启动，每个设备维持一个长生命周期的 shell，因此 cd、环境变量、后台状态在多次调用之间自然保留。

核心机制：哨兵法（sentinel）

telnet / 交互式 shell 没有天然的「命令结束」信号。rcmd 在每条命令后注入一个随机哨兵并回传 $?，从而精确判定命令边界与退出码：

发送：  <用户命令>
        __rc=$?; echo ___RCMD_<随机>___:$__rc
匹配：  ___RCMD_<随机>___:(\d+)     ← 括号里就是退出码，之前的内容 = 命令输出

哨兵单独一行发送（而非用 ; 拼接），这样命令里的尾部 # 注释或未闭合引号都不会吞掉哨兵。telnet 和 ssh 用同一套逻辑，协议差异只在如何建立那个连接。

命令

命令作用
rcmd exec <device> "<cmd>"在设备会话里运行命令，退出码透传（rcmd 自身退出码 == 远程命令退出码）
rcmd ls列出所有设备及连接状态
rcmd reset <device>断开并重连，清空会话状态（cd/env）
rcmd raw <device> "<keys>"发送原始按键（用于交互式程序，无退出码）
rcmd logs <device> [n]查看该会话最近 n 行原始 I/O（调试用）
rcmd stop停止 daemon

使用方法

1. 安装依赖

pip3 install --user pexpect   # 唯一依赖

2. 配置设备

编辑 devices.yaml，描述每个设备如何连接：

board:
  transport: telnet
  host: 192.168.22.166
  port: 23
  username: root
  password: ******
  login_prompt: "login:"          # 等这个再发用户名
  password_prompt: "[Pp]assword:" # 等这个再发密码
  shell_prompt: "[#$]"            # shell 就绪的提示符提示

server:
  transport: ssh
  host: 172.25.4.8
  port: 22
  username: song.yu
  password: ******               # 该主机用密码认证；也可留空走 key

3. 运行

cd rcmd

./rcmd exec server "uname -a"     # 退出码 = 远程命令退出码
./rcmd exec board  "cd /tmp"      # 状态保留...
./rcmd exec board  "pwd"          # ...下次生效 → /tmp
./rcmd exec board  "false"; echo $?   # → 1，真实的远程退出码
./rcmd ls                         # 查看设备与连接状态

给 AI 调用者的说明

  • exec 用于会正常返回的命令（有退出码）。它的退出码等于远程命令的退出码，判断成败的方式和本地命令一致。
  • 交互式程序（top、vi、tail -f、需要输入的 sudo）不会产生哨兵，会超时（默认 30s，可用 RCMD_TIMEOUT 调整）。这类请用 rcmd raw，或避免使用。
  • 会话有状态：一次调用里的 cd 会影响下一次。需要干净 shell 时用 rcmd reset <device>。
  • 超时后 rcmd 会自动发送 Ctrl-C 并重新同步，下一条命令能正常工作，无需手动 reset。

配置字段参考（devices.yaml）

字段telnetssh含义
transport✓✓telnet 或 ssh
host / port✓✓地址与端口
username✓✓登录用户
password✓○telnet 必需；ssh 用它或用 key
login_prompt✓发送用户名前等待的正则
password_prompt○○发送密码前等待的正则
shell_prompt○○交互 shell 的提示符正则（提示用）

环境变量：RCMD_CONFIG（配置文件路径）、RCMD_TIMEOUT（每条命令超时秒数）。

技术栈

  • 语言：Python 3（单文件，daemon + 客户端）
  • 交互控制：pexpect（telnet/ssh 长连接与哨兵匹配）
  • 通信：Unix domain socket（本机，长度前缀 JSON）

已知限制

  • exec 只适用于会返回的命令；交互式程序需走 raw，否则超时。
  • telnet 密码以明文存于 devices.yaml，注意文件权限（chmod 600）并加入 gitignore。
  • 目前一条命令在会话内串行执行；如需并发请为同一设备配置多个 device 名。
